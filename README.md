
# 💼 InsuranceWeb - 보험 업무 통합 시스템

> **Spring Boot 기반 보험사 통합 업무 관리 시스템**  
> 고객의 보험금 청구부터 관리자의 승인 처리까지  
> 실제 보험사 업무 흐름을 반영한 웹 애플리케이션입니다.

---

## 🧾 프로젝트 개요

**InsuranceWeb**은 보험 상품, 계약, 청구 등  
보험사 핵심 업무를 하나의 플랫폼에서 관리할 수 있도록 설계한  
**통합 보험 업무 시스템**입니다.  

고객용과 관리자용 웹 페이지를 분리하여  
보험금 청구, 계약 관리, 통계 시각화, 활동 로그 기록 등  
실제 보험사 시스템과 유사한 흐름을 구현했습니다.

## 💡 개발 동기

보험사의 계약·청구 업무는 복잡하고 문서 중심적인 절차가 많습니다.  
이를 전산화하여 사용자가 간편하게 보험금을 청구하고,  
관리자가 효율적으로 심사·승인할 수 있는  
**“실제 보험사와 유사한 전산 시스템”**을 구현하고자 했습니다.

## 🧭 시스템 아키텍처

```
Customer Web (Thymeleaf)
        ↓
Spring MVC Controller
        ↓
Service Layer (Business Logic)
        ↓
MyBatis DAO (XML Mapper)
        ↓
Oracle Database
```
 **고객용 모듈:** 보험상품 가입&계약, 보험금 청구, 계약 및 청구내역 조회, 가입상품 보기  
- **관리자용 모듈:** 계약관리, 청구 심사, 상품 관리, 대시보드 통계

---

## 🔄 전체 업무 흐름 (Business Flow)

[관리자] 보험 상품 등록
↓
[고객] 회원가입 및 상품 가입 → 보험 계약 생성
↓
[관리자] 계약 승인 (승인된 계약만 청구 가능)
↓
[고객] 승인된 계약에 한해 보험금 청구 진행 
↓
[관리자] 청구 심사 → 보험금 지급 승인/거절

이렇게 고객과 관리자의 업무가 **순차적으로 연결된 구조**로 설계되어 있으며,  
모든 프로세스는 DB 내 테이블 간의 관계로 긴밀히 연동되어 있습니다.  
예를 들어, 고객이 가입한 **`INSURANCE_CONTRACTS`** 가 승인 상태여야만  
**`CLAIMS`** 테이블에 청구 정보가 생성되도록 제약을 두어  
실제 보험사의 업무 규칙을 그대로 반영했습니다.

## 🧩 주요 구현 내용

### 📁 파일 업로드 경로 관리
- `application-prod.properties`에 `file.upload-dir`을 외부 설정으로 분리  
- EC2 환경에서도 프로젝트 디렉토리 내 `uploaded/` 하위 폴더 자동 생성  
- 고객 ID + 타임스탬프를 조합한 폴더명으로 관리  

### 💾 세션 기반 데이터 유지
- `HttpSession`을 이용하여 보험금 청구 7단계 간 데이터 유지  
- 사용자가 이전 단계로 돌아가도 입력한 정보가 그대로 복원  

### 📊 Chart.js 대시보드
- 월별 신규 계약, 해지 계약, 신규 청구, 승인 건수 시각화  
- DB에서 `EXTRACT(YEAR/MONTH)`로 월별 통계 집계

## 🧰 트러블슈팅

| 문제 상황 | 해결 방법 |
|------------|-----------|
| **AWS EC2에서 파일 업로드 경로 인식 안됨** | `System.getProperty("user.dir")` 기반 동적 경로 설정으로 해결 |
| **세션 만료 시 입력 데이터 손실** | 세션에 `Map<String, Object>` 형태로 저장 후 자동 복원 |
| **Chart.js 그래프가 상단에 닿는 문제** | `beginAtZero` 및 padding 옵션 추가로 시각화 개선 |
| **MyBatis alias 오류** | Mapper XML과 DTO 패키지명 통일하여 해결 |

## 🚀 실행 방법

```bash
# 1️⃣ JAR 실행 (prod 프로필)
java -jar -Dspring.profiles.active=prod InsuranceWeb-0.0.2-SNAPSHOT.jar

# 2️⃣ 접속 URL
고객 페이지: http://(IP주소):9900/kdInsuranceTeam
관리자 페이지: http://(IP주소):9900/kdInsuranceTeam/admin/login
```

> EC2 환경에서는 `file.upload-dir` 경로를 `/home/ec2-user/InsuranceWeb/uploaded/`로 지정

## 📈 ERD (Database Structure)

```
CUSTOMERS ─┬─ INSURANCE_CONTRACTS ─┬─ CLAIMS
            │                      ├─ CONTRACT_COVERAGE_ITEMS
            └─ PERSONS             └─ COVERAGE_DEFINITIONS
```

- 주요 테이블: `CUSTOMERS`, `INSURANCE_CONTRACTS`, `CLAIMS`, `INSURANCE_PRODUCTS`, `ADMIN_ACTIVITY_LOG`
- `CLAIMS` 테이블에 파일 경로 및 지급 상태 관리
